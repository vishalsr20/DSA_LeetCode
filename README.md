# DSA_LeetCode 🧩

This repository is where I practice Data Structures & Algorithms by solving problems from **LeetCode** and uploading my solutions daily.

Solutions are written in **C++**, and new problems are added regularly as I keep practicing and improving.

---

## 📌 About

- Solving LeetCode problems consistently to build strong DSA fundamentals
- Each problem is organized in its own folder named `<problem-number>-<problem-name>`
- Solutions are auto-synced using [LeetSync](https://github.com/apps/leetsync), which also logs runtime and memory stats
- Also includes practice implementations of core algorithms (like sorting techniques) built from scratch

---

## 📁 Structure

```
DSA_LeetCode/
├── <problem-number>-<problem-name>/
│   └── solution.cpp
├── ...
└── README.md
```
